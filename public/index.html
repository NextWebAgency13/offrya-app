01

02

Les missions d’autrui sont consultables uniquement par les professionnels validés par OFFRYA disposant d’un abonnement actif.

03

Échangez directement

La messagerie privée facilite le contact. Vous convenez ensuite librement des conditions de la prestation avec le professionnel.

CONNEXION SÉCURISÉE

Confirmez votre identité de connexion

Votre compte dispose déjà d’un dossier. Confirmez le code de votre application pour reprendre votre suivi ou votre accès sans recommencer l’inscription.

ÉTAPE 1 SUR 5

Identifions votre entreprise

Le numéro SIRET permet de retrouver votre société sur le registre officiel, sans saisir à nouveau ses informations.

Le nom de votre entreprise sera renseigné automatiquement.

ÉTAPE 2 SUR 5

Qui représente cette entreprise ?

Votre identité et votre fonction permettront à OFFRYA de contrôler votre autorisation de représenter l'entreprise.

Si vous n'êtes pas représentant légal, une autorisation devra être confirmée auprès de l'entreprise par un canal indépendant.

ÉTAPE 3 SUR 5

Sécurisez votre accès

Une application de double authentification protège votre compte et les missions qui vous seront confiées.

Scannez ce code avec votre application TOTP puis saisissez le code à six chiffres. Ne communiquez jamais la clé au support.

Compte sécurisé pour cette session.

Le dossier est examiné avant la souscription. Aucun accès aux missions n'est accordé à ce stade.

ÉTAPE 4 SUR 5

Suivi des vérifications

OFFRYA confirme votre identité et votre habilitation. Consultez le statut de chaque contrôle.
